# Game 42 — Merge 2048

## Pitch

Slide elemental cores around a foundry board; equal cores merge and double, every merge scores its new value, and the run ends when a board locks. Classic builds toward the Prime Core (2048) and lets you keep going. Foundry Trials set a target tile inside a move budget across 30 stages, Daily Core seeds today's board for everyone, Zen spawns only 2s with unlimited undo, and Blitz is a 90-second score rush.

## Art direction

A dark foundry frame with glowing element tiles whose palette comes from `2048:core-*`, the board paint from `2048:foundry-*`, the tile glow from `2048:glow-*` and the frame ring from `2048:sky-*`. Tiles animate with slide and merge pops; the Prime Core celebration adds a ring and aura. Lite and reduced-motion modes stop the drifting background and shorten animations without changing moves.

## Modes and match structure

| Mode | Board | Goal | Limit | Spawns | Undo |
| --- | --- | --- | --- | --- | --- |
| Classic | 3×3 / 4×4 / 5×5 / 6×6 | reach 2048 | none | 2s and 4s | difficulty-based |
| Foundry Trials | 4×4 | stage target (16 → 2048) | stage move budget | 2s and 4s | difficulty-based |
| Daily Core | 4×4 | date-set daily goal | 80 moves | 2s and 4s | difficulty-based |
| Zen | 3×3 / 4×4 / 5×5 / 6×6 | keep merging | board lock | 2s only | unlimited |
| Blitz | 4×4 | score rush | 90 s | 2s and 4s | difficulty-based |

1. **Classic:** the unlock-free baseline; reaching 2048 opens the Prime Core dialog with Keep going or New game.
2. **Foundry Trials:** 30 ordered stages; each stage names a target tile and a move budget, and clearing one unlocks the next and awards 1–3 stars.
3. **Daily Core:** the board is seeded from the local date and the target is set for the day; everyone gets the same run.
4. **Zen:** only 2s spawn, undo never runs out, and the run closes when no move remains.
5. **Blitz:** a 90-second clock; the final score is banked when time expires.

Difficulty changes spawn odds and undo limits only: Easy allows 8 undos and favours 2s, Normal allows 4, Hard allows 1 and favours 4s.

## Core rules

- Arrow/WASD or a swipe slides every core; equal neighbours merge into their sum and add that value to the score.
- Two merged pairs in one move satisfy Chain Reaction.
- A new core spawns after every effective move; ineffective moves are rejected.
- A board with no legal merges ends Classic, Zen, Trial or Daily runs; Blitz ends on its clock.
- Undo restores the previous board and score, up to the mode/difficulty allowance.
- An active run is snapshotted to local storage and offered as a resume.

## Scoring

Every merge adds the merged tile's value, so chaining a 2+2 into 4, 8 and 16 in one move pays 4 + 8 + 16. Trial and Daily wins bank the score accumulated in the run. The Prime Core merge itself pays 4096. Best score, best tile and best score per board size are saved separately.

## Records and persistence

Saved under `2048`:

- `bestScore`
- `merge2048.runsCompleted`, `wins`, `gameOvers`, `totalScore`, `bestTile`
- `merge2048.bestBySize` (`3`/`4`/`5`/`6`)
- `merge2048.completedTrials`, `trialWins`, `dailyCompletions`, `dailyBest`
- `merge2048.blitzRuns`, `blitzBest`, `zenRuns`, `zenBest`
- `merge2048.lastResult`, `lastMode`, `lastPlayed`, `activeRun`
- `level`, `unlocks`, `stars` for Foundry progression

`activeRun` stores the whole board, score, history, undo count, clock and mode so a refresh can continue exactly where the run stopped.

## Tutorial and controls

The menu describes each run type and the controls. Arrow keys/WASD or a swipe slide the board, U undoes, N starts a new run, H shows controls and M mutes. The HUD shows the goal line, the move or clock budget, the undo allowance and the current difficulty. A Statistics screen lists runs, wins, best tile, trial stars, daily and Blitz bests and unlocked achievements.
